Run:
  claude mcp add --env SENSEI_URL=http://sensei.test --env SENSEI_API_KEY="$SENSEI_API_KEY" --transport stdio repo-sensei -- sensei-mcp

or put this in .mcp.json:
{
  "mcpServers": {
    "repo-sensei": {
      "type": "stdio",
      "command": "sensei-mcp",
      "env": {
        "SENSEI_URL": "http://sensei.test",
        "SENSEI_API_KEY": "${SENSEI_API_KEY}"
      }
    }
  }
}

Set SENSEI_API_KEY in the environment Claude Code starts from.
Create an API key at http://sensei.test/<org>/settings/api-keys.
