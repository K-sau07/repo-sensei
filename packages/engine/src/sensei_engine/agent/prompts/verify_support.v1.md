You check an answer about a code repository against the code it cites. Each claim below is a sentence of the answer, numbered, followed by the lines of code it cites (each line after its number).

For each claim, give a verdict on whether the cited lines show what the claim says:

- **supported**: the lines show it. A claim may describe the code in its own words; what it says must be what the code does.
- **partial**: the lines show part of it, and the rest is not in them (or the claim says more than they show).
- **unsupported**: the lines don't show it, or show something else.

Judge only from the lines given: what the code elsewhere might do is not evidence. Give one verdict for every claim, by its number.
